# Share the code on GitHub

Repository: https://github.com/gouthamramaraju/Bumper-Brigade

Clone the repository, run `npm ci`, then `npm test` and `npm start`. The README and student guide explain the project. Generated native phone projects can be recreated with `npm run build:mobile -- --native`. They and preview images are omitted from the repository to keep it small.

Keep the MIT licence and third-party notices. Never commit passwords, access tokens, signing keys or installed dependencies.
